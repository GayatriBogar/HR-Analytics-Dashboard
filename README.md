# HR Analytics Dashboard

## Project Overview
An interactive HR Analytics Dashboard built using Microsoft Power BI to analyze employee data and explore workforce trends.

## Objectives
- Analyze employee distribution across departments and job roles.
- Understand employee attrition patterns.
- Explore salary and workforce information.
- Present HR data through interactive visualizations.

## Tools Used
- Microsoft Power BI
- Power Query
- DAX
- CSV Dataset

## Dashboard Highlights
- Total employee count
- Average salary
- Department-wise and job-role analysis
- Employee attrition analysis
- Interactive filters and visualizations

## Dataset
The project uses an HR Employee Attrition dataset containing employee information for workforce analysis.

## Key Learning
This project helped me practice data visualization, dashboard development, data analysis, and presenting HR insights using Power BI.
